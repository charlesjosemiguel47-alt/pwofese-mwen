PWOFESÈ MWEN — VÈSYON POU CHROME (PWA)

Fichye sa yo prepare pou mete aplikasyon an sou Cloudflare Pages.

1. Kenbe tout fichye sa yo ansanm nan menm dosye a.
2. Lè w ap itilize Cloudflare Pages, chwazi Direct Upload epi telechaje fichye yo/dosye a.
3. Apre piblikasyon an, louvri lyen pages.dev la nan Chrome sou Android.
4. Nan meni twa pwen Chrome nan, chwazi Install app oswa Add to Home screen.

NÒT:
- Sit la dwe sèvi sou HTTPS pou enstalasyon PWA a mache.
- Fè chanjman nan index.html epi pibliye nouvo vèsyon an lè gen mizajou.
- Pa pataje modpas Gmail, GitHub oswa Cloudflare ak pèsonn.
